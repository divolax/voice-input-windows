# Сообщение и выдача в Telegram-боте

Ссылки уже настроены на публичный GitHub Release. Не публикуйте установщик повторно из локальной папки: бот должен вести на актуальный GitHub Release.

## Сообщение после `/start voice_input`

**Бесплатный голосовой ввод для Windows**

Удерживай `Ctrl` + `Alt`, говори и отпусти клавиши. Текст появится в активном поле. Распознавание идёт локально на компьютере.

1. Скачай и установи приложение.
2. При первой диктовке подключись к интернету: Whisper `base` загрузится автоматически (около 150 МБ).
3. Нажми `Ctrl` + `Alt`, продиктуй текст и отпусти клавиши.
4. Управляй паузой и автозапуском через значок микрофона рядом с часами.

Аудио не отправляется на сервер и не сохраняется. Распознанные фразы остаются на компьютере. Нужны Windows 10/11 x64 и микрофон.

Если Windows предупредит о неизвестном издателе, проверь источник файла: установщик пока не подписан сертификатом. Скачивай его только по кнопке ниже.

## Кнопки

- **Скачать установщик для Windows** → https://github.com/divolax/voice-input-windows/releases/latest/download/VoiceInput-Setup-0.2.0-x64.exe
- **Скрипты (ZIP)** → `VoiceInput-Source-0.2.0.zip` отправляется ботом как документ.
- **Инструкция Word** → `VoiceInput-Guide-RU.docx` отправляется ботом как документ.
- **Все файлы на GitHub** → https://github.com/divolax/voice-input-windows/releases/latest

Ссылка на отдельный сценарий в боте и QR-код в DOCX: https://t.me/present_ai_dima_bot?start=voice_input

Установщик около 90 МБ, поэтому скачивается с GitHub. Маленькие ZIP и DOCX бот загружает и отправляет человеку прямо в Telegram.

## Обновление

Собери новую версию, создай тег `vX.Y.Z` и отправь его в GitHub. Workflow опубликует установщик в Releases. После изменения версии обнови имена и ссылки в боте. Текущая ссылка скачивания установщика:

https://github.com/divolax/voice-input-windows/releases/latest/download/VoiceInput-Setup-0.2.0-x64.exe
