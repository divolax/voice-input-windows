# Локальный голосовой ввод — план MVP

## Цель
Локально распознавать русскую речь и вставлять результат в текущее активное поле по жесту `Ctrl` + `Alt`.

## Целевая среда
- Windows 10/11 x64.
- CPU `int8`; специальная видеокарта и CUDA не нужны.
- Пользовательский микрофон по умолчанию.

## Решения
1. `faster-whisper` в `cpu` / `int8`: не требует CUDA и работает локально.
2. Модель `base`: первоначальная загрузка примерно 145 МБ. Это компромисс качества русского и места. Заменяется настройкой `WHISPER_MODEL`.
3. `sounddevice`: запись напрямую с системного микрофона.
4. `pynput`: глобальное отслеживание нажатий `Ctrl` и `Alt` без интерфейса.
5. `pyperclip` и программное `Ctrl+V`: вставка поддерживается в большинстве приложений Windows.

## Алгоритм
1. При одновременном удержании `Ctrl` и `Alt` очищается аудиобуфер и включается запись.
2. При отпускании любой из этих клавиш запись останавливается.
3. Запись короче 0.25 с пропускается.
4. Модель распознаёт аудио на русском; пустой результат не вставляется.
5. Текст копируется в clipboard, вставляется в активное окно; старый clipboard восстанавливается, только если пользователь его не менял.

## Критерии готовности
- Зависимости ставятся через `install.ps1`.
- Приложение запускается через `start.ps1`.
- Скрипт и тесты проходят синтаксическую/модульную проверку.
- При первой диктовке модель автоматически загружается и сохраняется в локальном кэше.
- Сборка установщика, запуск из трея, переключение паузы, автозапуск и выход проверяются перед публикацией.
- Работа микрофона и вставки подтверждается на тестовой Windows-системе.
