# Voice Input — бесплатный локальный голосовой ввод для Windows

Удерживайте `Ctrl` + `Alt`, продиктуйте текст и отпустите клавиши. Voice Input распознает русскую речь на этом компьютере и вставит текст в активное поле. Приложение работает в системном трее рядом с часами.

## Установка для пользователей

1. Скачайте `VoiceInput-Setup-0.2.0-x64.exe` со страницы **Releases** этого GitHub-репозитория или получите установщик в Telegram-боте автора.
2. Запустите установщик. Установка выполняется только для вашей учетной записи Windows; права администратора не нужны.
3. Оставьте отмеченным запуск после установки. Значок микрофона появится в области уведомлений рядом с часами. Если Windows скрыла значок, нажмите `^` рядом с системным треем и перетащите его на панель.
4. Кликните в текстовое поле, зажмите обе клавиши `Ctrl` и `Alt`, говорите, затем отпустите клавиши. После распознавания текст вставится в поле.
5. Правый клик по значку открывает паузу/возобновление, историю, папку данных, автозапуск и выход.

На первой диктовке нужен интернет: приложение автоматически загрузит модель распознавания Whisper `base` (около 150 МБ) и сохранит её в кэш Windows. После этого распознавание работает без интернета. Приложение не отправляет аудио на сервер и не сохраняет аудиозаписи. Распознанный текст хранится локально — последние 10 фраз в истории.

## Требования

- Windows 10 или 11, x64.
- Микрофон, выбранный устройством ввода Windows.
- Интернет только для первоначальной загрузки модели.
- Свободное место: примерно 150 МБ под модель плюс место для приложения.

Программа использует CPU (`int8`) и не требует NVIDIA/CUDA. Скорость распознавания зависит от компьютера и длины диктовки. Основной язык модели — русский.

## Настройки через значок в трее

- **Пауза голосового ввода / Включить голосовой ввод** — останавливает и снова запускает горячую клавишу и микрофон.
- **Открыть историю диктовок** — открывает резервную копию текста, если поле потеряло фокус или вставка не сработала.
- **Открыть папку данных** — показывает локальные файлы приложения.
- **Включить/Отключить автозапуск** — управляет запуском при входе в Windows.
- **Выход** — полностью закрывает приложение.

Данные пользователя находятся в `%LOCALAPPDATA%\VoiceInput`. Удаление приложения не удаляет эту папку автоматически: при необходимости удалите её вручную после сохранения истории.

## Если что-то не работает

- **Нет значка:** откройте «Пуск» → `Voice Input`. Убедитесь, что приложение не поставлено на паузу.
- **Не видит микрофон:** выберите устройство ввода по умолчанию в параметрах Windows → Система → Звук; проверьте разрешение доступа к микрофону для классических приложений.
- **Модель не загрузилась:** подключитесь к интернету и повторите диктовку. Причина записывается в `%LOCALAPPDATA%\VoiceInput\dictation.log`.
- **Текст не вставился:** сначала поставьте курсор в поле. История находится в `%LOCALAPPDATA%\VoiceInput\history.txt`.
- **Горячая клавиша конфликтует с программой:** закройте эту программу или временно поставьте Voice Input на паузу из трея.
- **Защитник Windows предупреждает о неизвестном издателе:** установщик пока не подписан сертификатом. Скачивайте его только по ссылке из официального канала автора и странице Releases репозитория.

## Сборка разработчиком

Сборка установщика выполняется на Windows x64. Нужны Python 3.11 или 3.12 и Inno Setup 6.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\build.ps1
```

Готовый каталог приложения появляется в `dist\VoiceInput`, установщик — в `build\installer`. Для сборки только каталога приложения используйте `.\build.ps1 -SkipInstaller`. PyInstaller должен собирать Windows-приложение на Windows; кросс-сборка не поддерживается.

Чтобы обновить только установщик без повторной сборки Python-приложения, используйте `.\build.ps1 -SkipBundle -Version 0.2.1`. Для автоматической публикации нового релиза запушьте тег `v0.2.1`; workflow соберёт установщик и создаст GitHub Release.

Для запуска из исходников: `.\install.ps1`, затем `.\start.ps1`.

## Раздача через Telegram

Для пользователей бот отправляет инструкцию и кнопку **Скачать установщик** со ссылкой на GitHub Release. Сценарий сообщения и кнопок находится в `TELEGRAM_MESSAGE.md`. Это надёжнее прямой отправки установщика: текущий файл больше 50 МБ, а Telegram Bot API ограничивает загрузку обычных документов. Токен бота не хранится в этом репозитории.
