# Voice Input — бесплатный локальный голосовой ввод

Voice Input превращает речь в текст прямо на компьютере. Удерживайте клавиши записи, говорите и отпустите их: распознанный текст вставится в выбранное поле. Приложение работает в системном трее Windows или в строке меню Mac.

## Скачать

Откройте [Present AI Дима в Telegram](https://t.me/present_ai_dima_bot?start=voice_input) или [GitHub Releases](https://github.com/divolax/voice-input-windows/releases/latest).

- **Windows 10/11, x64:** [скачать установщик EXE](https://github.com/divolax/voice-input-windows/releases/latest/download/VoiceInput-Setup-0.3.0-x64.exe)
- **MacBook с Apple silicon (M1, M2, M3, M4):** [скачать DMG для arm64](https://github.com/divolax/voice-input-windows/releases/latest/download/VoiceInput-0.3.0-macos-arm64.dmg)
- **MacBook с Intel:** [скачать DMG для x86_64](https://github.com/divolax/voice-input-windows/releases/latest/download/VoiceInput-0.3.0-macos-x86_64.dmg)

Чтобы узнать процессор Mac, откройте меню Apple → «Об этом Mac». Если там указан чип Apple M, выбирайте Apple silicon; если указан процессор Intel — версию Intel.

## Установка на Windows

1. Скачайте `VoiceInput-Setup-0.3.0-x64.exe` и дважды щёлкните по нему в папке «Загрузки».
2. Нажмите **Install / Установить**. Программа устанавливается для вашей учётной записи Windows; права администратора не нужны.
3. Оставьте включённым запуск после установки. Значок микрофона появится рядом с часами. Если он скрыт, нажмите стрелку `^` в системном трее.
4. Щёлкните по полю для текста, зажмите `Ctrl` и `Alt`, говорите и отпустите клавиши.
5. Нажмите значок правой кнопкой, чтобы поставить программу на паузу, открыть историю, управлять автозапуском или выйти.

## Установка на macOS

Поддерживается macOS 11 или новее.

1. Скачайте DMG для процессора вашего Mac, откройте файл и перетащите **Voice Input** в папку **Applications / Программы**. Затем извлеките образ диска.
2. Откройте **Applications / Программы** и запустите Voice Input. Поскольку приложение пока не нотарифицировано Apple, macOS может показать предупреждение. Если запуск заблокирован, откройте **System Settings → Privacy & Security**, прокрутите до раздела Security и нажмите **Open Anyway**, затем подтвердите **Open**.
3. При первом запуске разрешите доступ к микрофону. Для записи сочетания клавиш откройте **System Settings → Privacy & Security → Input Monitoring** и **Accessibility**, включите Voice Input в обоих списках и перезапустите приложение. Настройки macOS могут называться немного иначе в зависимости от версии.
4. Значок микрофона появится в строке меню вверху экрана. Щёлкните по полю для текста, зажмите `Control` и `Option`, говорите и отпустите клавиши. После распознавания Voice Input вставит текст через `Command` + `V`.
5. В меню значка можно поставить ввод на паузу, открыть историю, включить автозапуск при входе в систему или закрыть приложение.

macOS запрашивает эти разрешения, потому что приложение слушает сочетание клавиш в других программах и вставляет текст в активное поле. Voice Input не записывает экран и не отправляет аудио на сервер.

## Первое использование и приватность

Для первой диктовки нужен интернет: Voice Input один раз скачает модель распознавания Whisper `base` (около 150 МБ). После этого распознавание работает на компьютере без интернета. Приложение использует процессор и не требует NVIDIA/CUDA.

Аудио не отправляется на сервер и не сохраняется. Последние 10 распознанных фраз хранятся локально:

- Windows: `%LOCALAPPDATA%\VoiceInput`
- macOS: `~/Library/Application Support/VoiceInput`

Удаление программы не удаляет историю автоматически. Сначала сохраните нужный текст, затем удалите папку с данными вручную.

## Если что-то не работает

- **Нет значка:** откройте Voice Input из меню «Пуск» Windows или из папки Applications на Mac. Проверьте, что приложение не поставлено на паузу.
- **Не слышит микрофон:** проверьте выбранный микрофон в настройках звука и разрешение для Voice Input в настройках конфиденциальности.
- **Горячая клавиша не срабатывает на Mac:** включите Voice Input в Input Monitoring и Accessibility, затем полностью закройте и снова откройте приложение.
- **Модель не загрузилась:** подключитесь к интернету и повторите диктовку. Диагностика находится в `dictation.log` внутри папки VoiceInput.
- **Текст не вставился:** перед диктовкой щёлкните мышью в нужном поле. Распознанный текст можно открыть через «Открыть историю диктовок».
- **Windows предупреждает о неизвестном издателе или macOS — о неизвестном разработчике:** сборки пока не подписаны сертификатом разработчика. Сверьте файл с официальной страницей Releases перед запуском.

## Скриптовый вариант для Windows

В Releases и Telegram-боте доступен ZIP с исходниками. Он требует Python 3.11/3.12 и запуска PowerShell-сценариев. Для Mac и большинства пользователей проще скачать готовый DMG или EXE.

## Сборка разработчиком

Windows-сборка требует Python 3.12 и Inno Setup 6; macOS-сборки выполняются на GitHub Actions отдельно для arm64 и x86_64. PyInstaller собирает приложение на целевой ОС; Windows-версия не заменяет сборку для Mac.

Для создания релиза создай тег `vX.Y.Z` и отправь его в GitHub. Workflow соберёт Windows-установщик и два macOS DMG для одной версии.
