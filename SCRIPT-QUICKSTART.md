# Запуск из исходников

Этот ZIP — запасной вариант для пользователей, которым подходит запуск программы через Python и PowerShell. Для обычной установки на Windows проще скачать установщик EXE: он уже включает нужные компоненты.

## Что потребуется

- Windows 10 или 11, 64-разрядная версия.
- Python 3.11 или 3.12 с сайта python.org. В установщике включите **Add Python to PATH**.
- Микрофон и интернет для первой загрузки модели Whisper base (около 150 МБ).

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте папку в Проводнике.
3. Запустите `install.ps1` через PowerShell и дождитесь установки библиотек.
4. Запустите `start.ps1`. Пока приложение работает, окно PowerShell должно оставаться открытым.
5. Щёлкните по полю для текста, удерживайте `Ctrl` + `Alt`, говорите и отпустите клавиши.

Приложение и этот вариант хранят историю на компьютере. Аудио не отправляется на сервер. Если PowerShell запрещает запуск сценария, используйте EXE-установщик или обратитесь за помощью в Telegram-бот автора.
